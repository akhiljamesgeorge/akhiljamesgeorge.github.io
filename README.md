# Akhil James Portfolio — Refactored

This version is intentionally built with **plain HTML, CSS and vanilla JavaScript**.

## Why no React/Vue/etc.?

For a single-page personal portfolio, a framework would add build tooling and dependencies
without solving a problem that this site currently has. The static version:

- loads quickly,
- is easy to maintain,
- works directly on GitHub Pages,
- has no JavaScript framework dependency,
- avoids jQuery, Typed.js, Waypoints and Owl Carousel,
- is easy to edit years from now.

## Files

- `index.html`
- `style.css`
- `script.js`
- your existing `images/` directory

The page still expects these two existing image paths:

- `images/workplace_black_1.jpg`
- `images/inPixio_CV.png`

Copy the existing `images` directory from your current repository into the same folder as
the three refactored files.

## Publish on GitHub Pages

Your current URL suggests you are using the user-site repository:

`akhiljamesgeorge.github.io`

To update it:

1. Back up the current repository or create a branch.
2. Replace the root `index.html`, `style.css` and `script.js` with these versions.
3. Keep the existing `images/` directory in the repository root.
4. Commit and push to the branch GitHub Pages is currently serving (normally `main`).
5. In GitHub: **Settings → Pages**.
6. Confirm the site is deployed from the intended branch/root.
7. Open `https://akhiljamesgeorge.github.io/` after the deployment completes.

## Good next content upgrades

The biggest remaining improvement is not technical — it is content.

A strong 2026 professional portfolio would benefit from adding:

- current role / recent experience,
- 2–4 concrete projects with your personal contribution,
- quantified outcomes where appropriate,
- an updated MBA status,
- optionally a downloadable CV.

Those should be added only with information you are comfortable publishing publicly.
